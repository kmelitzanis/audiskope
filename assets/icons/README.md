# Audiskope icons

The six appearances in `variants/` — Default, Dark, TintedDark, TintedLight, ClearDark and ClearLight — are generated by `pnpm run logo` from one geometry, each keeping the colours its hand-drawn predecessor used.

`pnpm run icons` uses Default.png as the master for desktop ICNS/ICO/PNG, web, Android raster icons and the iOS default catalog, preserving transparency. Python 3 and Pillow are required only to regenerate the committed exports.

Bar geometry is defined once in `scripts/generate-logo-variants.py`: five bars, 0.088 of the canvas wide with 0.048 gaps, running 0.28 to 0.86 of its height. The titlebar mark in `src/renderer/index.html` (with its stroke width in `styles.css`) and the DMG background in `scripts/generate-dmg-background.py` repeat those proportions, so change all three together.

All six supplied appearances are available as separate image sets in `ios/Appearances.xcassets`. These are reusable assets, not automatic desktop theme switching. The desktop application uses Default. The generated PNGs carry their own rounded silhouette; they are not claimed to be validated App Store submission assets. Future native iOS releases should use the original Icon Composer project for platform-managed appearances and masks.

Android adaptive foreground uses the Default artwork inside its safe area; its monochrome vector remains the equalizer symbol. The web manifest uses ordinary icons rather than applying a second adaptive mask. `logo.svg` is the vector form of the same mark, regenerated alongside the variants.
